주린이 기업 노트 개인정보처리방침

시행일: 2026년 11월 14일

1. 수집하는 개인정보

주린이 기업 노트는 이름, 이메일, 전화번호, 위치 등 개인정보를 수집하지 않아요. 회원가입과 로그인도 없어요.

2. 폰 안에 저장되는 정보

배우기 진도(배운 용어, 퀴즈 기록)는 사용자의 폰 안에만 저장돼요(shared_preferences). 개발자나 다른 서버로 보내지 않아요. 앱을 지우면 함께 사라져요.

3. 인터넷 연결

앱은 켤 때 GitHub에 올려 둔 공개 데이터 파일(뉴스 요약, 일정, 수업 등)만 받아요. 이때 요청한 기기의 IP 주소 등은 GitHub가 자체 방침에 따라 처리해요. 개발자는 이 정보를 받지 않아요.

4. 광고와 제3자 제공

지금은 광고 SDK가 없고, 개인정보를 제3자에게 제공하지 않아요. 나중에 광고를 넣으면 이 문서를 먼저 고칠게요.

5. 문의

궁금한 점은 GitHub 저장소 이슈로 남겨 주세요.

6. 안내

이 앱은 투자 공부용 정보를 제공하며, 매수·매도 추천이 아니에요.
