# 주린이 걸음마: 매일 10분 배우기 — 설계

2026-11-14 · 대상 앱: `jurini_app` (Flutter, 안드로이드) · 관련: CLAUDE.md

## 1. 왜 하는가
경제 정보는 증권사 앱과 유튜브에 넘친다. 1인 개발 무료 앱이 살아남을 자리는 **"완전 처음인 사람이 순서대로 하나씩 깨우치게 해 주는 곳"**이다(주인 결정). 앱의 중심을 '찾아보는 사전·도구'에서 **'매일 조금씩 배우는 길'**로 옮긴다.

**성공의 모습 (주인의 말):** 완전 초보가 한 달쯤 쓰고 나면 **뉴스를 보고 시장이 왜 움직였는지 스스로 이해**한다. 그리고 경제용어를 **순서대로 배우는 단계**가 앱 안에 있다.

**쓰는 장면 (주인의 말):** 쇼츠에 익숙한 사람들이라 길게 못 본다. **매일 10분**, 잠깐씩 하면 배울 수 있어야 한다.

## 2. 목표 / 안 할 것 / 실패로 보는 것
**목표**
1. 매일 10분짜리 '오늘의 배우기' 한 바퀴: 오늘의 수업 → 오늘의 뉴스 읽기 → 복습 퀴즈.
2. 정해진 5단계 코스(A): 뉴스를 읽을 수 있게 되는 순서로 용어를 배운다.
3. 끝없이 이어지는 AI 수업(B): 매일 그날 뉴스로 새 수업을 만든다. 코스(A)를 다 끝내도 배울 거리가 사라지지 않게 한다(주인 요구).
4. 뉴스 → 배우기 연결: 뉴스마다 "이 뉴스를 이해하려면" 용어·수업으로 바로 간다.
5. 연결 탭: 회사 **검색창**과 **업종(섹터)별 묶음**(주인 요구, 교육과 별개의 작은 수정).

**안 할 것 (이번 범위 밖)**
- 로그인·계정·서버 저장(진도는 폰 안에만). 푸시 알림. 유료 기능. 친구·랭킹 같은 소셜.

**실패로 보는 것 (기술적으로 돌아가도 실패)**
- 투자 추천·주가 예측처럼 읽히는 내용 (앱 전체 규칙: 화면마다 "매수·매도 추천이 아닙니다").
- 한 번에 길게 읽어야 하는 수업 (10분을 넘김).
- AI가 만든 틀린 설명이 검사 없이 초보자에게 나감.
- 매일 하라고 압박하는 장치(끊기면 벌을 주는 식)로 피로감을 주는 것.

## 3. 지켜야 할 조건
- 무료 + 광고 예정, 1인 개발, 예산 작음. 서버 없음: 데이터는 앱 안 JSON + 깃허브 `docs/`에서 받은 최신본(못 받으면 앱 안 복사본).
- AI 작업은 Claude Code 예약 작업(클라우드, 지금 구독 안에서 돌아감)으로 한다. **모든 AI 결과는 검사 스크립트를 통과해야만 저장**한다(기존 `check_news.py`, `check_calendar.py`와 같은 방식).
- 클라우드 작업은 많은 사이트에 직접 접속이 막혀 있어 WebSearch로 확인한다(2026-11-14 확인).
- 문장은 중학생도 이해할 쉬운 한국어. 앱 디자인 규칙(CLAUDE.md 디자인 토큰, Pretendard, 다크) 그대로. 디자인 작업 때는 디자인 스킬(impeccable·ui-ux-pro-max)을 켠다.
- 기존 재료를 버리지 않는다: 경제용어 138개(뜻·예시·주가에 왜 중요할까·시장 영향), 퀴즈(`makeQuiz`), AI 뉴스 요약(`docs/news.json`, 하루 2번), 경제 일정(`docs/calendar.json`), 기업 노트, 연결 지도.

## 4. 만드는 방법 (검토한 것과 고른 것)
| 방법 | 내용 | 득실 |
|---|---|---|
| A. 정해진 코스 + 뉴스 자동 연결 | 수업 약 25개를 미리 써 두고, 뉴스에 '관련 용어' 표시를 붙여 그날 뉴스를 수업 예시로 잇는다 | 순서가 탄탄하고 미리 검증 가능. 수업을 다 끝내면 새 내용이 없다 |
| B. 매일 AI가 수업 생성 | 그날 뉴스로 AI가 새 수업을 만든다 | 끝이 없다. 순서가 들쭉날쭉하고 틀린 내용 위험 |
| C. 용어사전에 단계 표시만 | 기존 사전·퀴즈에 단계 표시 | 가장 싸지만 '매일 배우는 경험'이 약함 |

**고른 것: A + B (주인 결정).** A로 기초 5단계를 깔고, B는 처음부터 매일 '오늘의 뉴스 수업'으로 함께 나온다. A를 다 끝낸 사람에게는 B가 '오늘의 수업' 자리를 이어받는다. 이유(주인): 준비한 수업이 다 떨어져도 내용이 계속 이어져야 한다.

## 5. 설계

### 5-1. 5단계 코스 (A) — 주인이 동의한 순서
각 단계는 "이 단계를 마치면 이런 뉴스를 읽을 수 있어요" 예시를 가진다.
1. **주식이 뭐예요** — 주식·시가총액·코스피·코스닥·주가지수·ETF … → "삼성전자 시총 1위"
2. **회사 성적표** — 매출·영업이익·순이익·실적 발표·컨센서스·어닝 서프라이즈·가이던스 … → "엔비디아 어닝 서프라이즈"
3. **주가가 비싼가요** — PER·PBR·밸류에이션·배당수익률 … → "고평가 논란"
4. **돈의 가격, 금리** — 기준금리·FOMC·인플레이션·CPI·금리 인상/인하 … → "CPI 발표에 증시 출렁"
5. **흐름을 잇기** — 환율·경기침체·공급망·경기민감주 … → "환율 오르면 수출주 강세"
- 단계당 수업 약 5개, 전체 약 25개(하루 1개 → 약 한 달, 주인의 '한 달' 기준과 맞춤).
- 수업 하나 = **카드 4~5장**(한 장 80자 안팎, 옆으로 넘김) + **퀴즈 3문제**. 5분 안.
- 수업은 기존 용어 id를 가리킨다(`terms`). 카드에서 용어를 누르면 기존 용어 팝업.
- 수업 글은 개발 쪽(Claude)이 쓰고, 사실 확인 후 넣는다. 데이터 파일: `jurini_app/assets/lessons.json`(앱 안에만, 고정).

### 5-2. 매일 AI 수업 (B)
- 새 예약 작업(하루 1번, 아침 뉴스 정리 뒤)이 그날 `docs/news.json`에서 **가장 배울 거리가 큰 뉴스 1개**를 골라 A와 **같은 모양**의 수업 1개(카드 4~5장 + 퀴즈 3문제)를 만든다.
- 수업이 기존 사전에 없는 용어를 쓰면, 그 용어를 함께 제안한다(뜻·예시·주가에 왜 중요할까). 앱은 이 'AI 추가 용어'를 사전에 합쳐 보여주되 "AI가 추가한 용어" 표시를 붙인다.
- 검사 스크립트(`check_lesson.py`): 형식, 길이, 금지 표현(추천·주가 예측·주가 숫자), 출처 url, 퀴즈 정답이 보기 안에 있는지, 용어 id가 존재하는지.
- **사실 확인 (주인 결정: AI 이중 확인):** 수업을 만든 뒤 별도의 확인 단계(다른 AI 세션 또는 같은 작업의 두 번째 단계)가 카드·퀴즈·새 용어의 사실 하나하나를 공식 자료(WebSearch, 공식 도메인 우선)로 다시 확인한다. 틀린 문장은 고치고, 확인 못 한 문장은 뺀다. 확인 통과 표시(`verified: true`, 확인한 출처 목록)가 없는 수업·용어는 검사기가 거절한다.
- **AI 추가 용어는 확인을 통과하면 사전에 계속 남는다**(별도 파일 `docs/glossary_ai.json`, 앱이 기존 사전에 합쳐 'AI가 추가한 용어' 표시). 수업은 60일 보관.
- **난이도 표시:** B 수업마다 1~5단계 중 어느 단계 내용인지(`stage`)를 붙인다. 코스를 하는 중인 사람에게도 숨기지 않고 '오늘의 10분' 아래 '보너스 수업'으로 보여주며, 아직 안 배운 단계면 "4단계 내용이에요" 안내.
- 결과: `docs/lesson_today.json`(오늘 수업) + `docs/lessons_ai.json`(최근 60일 보관함). 앱은 켤 때 받는다.
- 화면에 "AI가 만든 수업이에요. 틀릴 수 있어요" 표시.

### 5-3. 오늘의 배우기 (매일 10분)
```
┌ 오늘의 10분 ───────────────────────┐
│ ① 오늘의 수업 (5분)  2단계-3: 영업이익   │  ← A 다음 수업, A를 다 끝냈으면 B 수업
│ ② 오늘의 뉴스 읽기 (3분)               │  ← 오늘 뉴스 1개 + "이 뉴스 읽는 법"
│ ③ 복습 퀴즈 (2분)  배운 용어 3문제        │  ← 기존 makeQuiz를 '배운 용어'로
│ ─────────────────────────────────── │
│ 이번 주 4일 공부 · 5단계 중 2단계          │
└────────────────────────────────────┘
```
- ① A의 다음 수업. 하루 수업 수는 막지 않는다: 끝내면 "다음 수업 계속하기"로 진도가 실제로 나간다. A를 다 끝낸 사람은 ①이 B 수업.
- ② 뉴스 읽기: **뉴스 정리 작업에 '오늘의 시장' 칸을 새로 만든다**(금리·물가·환율·증시 전체 흐름 뉴스 2~4개, 회사 뉴스와 같은 형식 + 왜 움직였는지). 지금 `docs/news.json`은 회사 뉴스만 있어서 '시장이 왜 움직였는지'를 가르칠 재료가 없기 때문(만드는 쪽 판단). 뉴스 정리 작업이 뉴스마다 `terms`(관련 용어 id 1~3개)와 `learn`(이 뉴스를 그 용어로 읽는 법 한두 문장)을 함께 쓴다. 지금까지 배운 용어와 겹치는 뉴스를 우선 고른다.
- ③ 복습: 배운 용어에서 3문제. 틀린 용어는 다음 날 다시 나온다.
- 진행 표시는 **부드럽게**: '이번 주 며칠 공부'와 단계 진행만. 끊겼다고 벌주는 표현은 쓰지 않는다.

### 5-3b. 오늘의 시장 한눈에 (배우기 탭 맨 위)
앱을 켜면 처음 보이는 칸. 오늘 주요 일정(있으면, `docs/calendar.json`)과 '오늘의 시장' 뉴스 한 줄 + "이 뉴스 이해하기: [용어]" 칩. 화면을 막는 팝업은 쓰지 않는다(주인이 팝업을 물었고, 매일 닫는 수고와 무시되는 문제 때문에 이 칸으로 대신하기로 제안 — 주인 최종 확인 대기). 진짜 푸시 알림은 이번 범위 밖.

### 5-4. 진도 저장
폰 안에만 저장(로그인 없음): 끝낸 수업 id, 배운 용어 id, 틀린 용어 id, 공부한 날짜 목록. 앱을 지우면 사라진다는 점은 설정·안내에 한 줄로 알린다.

### 5-5. 뉴스 → 배우기 연결
뉴스 탭 카드와 기업 상세 뉴스 칸에 "이 뉴스 이해하기: [금리] [CPI]" 칩. 누르면 용어 팝업, 그 용어를 다루는 A 수업이 있으면 "수업으로 배우기" 버튼.

### 5-6. 화면 배치
하단 탭은 5개가 최대다. **'퀴즈' 탭을 '배우기' 탭으로 바꾸고**(기존 자유 퀴즈는 배우기 탭 안 '자유 퀴즈'로 이동), **앱을 켜면 배우기 탭이 먼저** 열린다(주인 확정). 순서: 배우기 / 기업 / 연결 / 용어사전 / 뉴스.
배우기 탭 = 오늘의 시장 한눈에 → 오늘의 10분 카드 → 보너스 AI 수업 → 5단계 코스 지도(끝낸 수업 표시) → AI 수업 보관함 → 자유 퀴즈.

### 5-7. 연결 탭 (별도 작은 수정)
회사 칩 줄 대신: 검색창(회사 이름·티커) + 업종별 묶음(기존 회사 데이터의 업종으로 묶고, 묶음을 펼쳐 회사 선택). 고른 뒤 그림·카드는 지금과 같다.

## 6. 주인이 정한 것
- 교육 중심으로 방향 전환. 성공 = 뉴스 보고 시장이 왜 움직였는지 이해.
- 매일 10분, 짧게 끊어서.
- 5단계 순서(위 5-1).
- A + B를 모두 넣는다.
- 연결 탭에 검색창과 업종별 묶음.
- AI 수업·용어는 AI 이중 확인(사실 확인 단계)을 거친다. 확인된 AI 용어는 사전에 계속 남는다.
- 배우기 탭이 첫 화면.

## 7. 만드는 쪽이 정한 것 (주인 검토용)
- 뉴스 정리에 '오늘의 시장' 칸 추가 (시장 전체 뉴스 재료가 없어서).
- B 수업에 단계 표시, 코스 중인 사람에게도 '보너스 수업'으로 보여줌(숨기지 않음).
- 하루 수업 수 제한 없음.
- 팝업 대신 배우기 탭 맨 위 '오늘의 시장 한눈에' 칸.

## 8. 만드는 쪽에 맡기는 것
- 수업 25개의 구체 문장, 퀴즈 문제(사실 확인 필수).
- 파일 형식 세부, 화면 세부 디자인(기존 디자인 규칙 안에서, 디자인 스킬 사용).
- 진도 저장 방법(작은 저장 패키지 추가 가능).
- B 예약 작업의 시각(뉴스 정리 작업 뒤), 보관 기간(60일 제안).
- 단계별 수업 개수(약 5개, 용어 양에 따라 4~6).
