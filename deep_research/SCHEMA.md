# 기업 깊이 노트 형식 (deep_research/deep_N.json)

앱의 새 중심: "이 회사는 무엇을 만든다"가 아니라 **어떤 기술·능력이 있고, 그게 어떤 미래(비전)로 이어지며, 경쟁사와 무엇이 달라서 투자 포인트가 되는가**를 주식 초보가 읽고 이해하게 한다.

```json
{"companies": {
  "TSLA": {
    "asof": "2026-11-18",
    "summary": "한 문단(80~260자). 이 회사가 진짜로 무엇으로 돈을 벌고, 어디로 가려는지.",
    "tech": [   // 3~5개: 이 회사를 이 회사로 만드는 핵심 기술·능력(제품 이름 나열 X)
      {"name": "FSD(자율주행) 소프트웨어",
       "what": "무엇인지 쉬운 말로 (40~220자). 비유 환영.",
       "why": "이게 왜 중요한지, 어떤 미래·돈벌이로 이어지는지 (40~220자)",
       "edge": "경쟁사 기술과 무엇이 다른지, 그 근거(숫자·사실) (40~220자)"}
    ],
    "vision": {
      "goal": "회사가 스스로 밝힌 장기 목표 (40~240자, 회사 발표 기준)",
      "milestones": [ {"when": "2025" | "2026-06" | "2027년 하반기", "what": "5~120자", "status": "done" | "planned"} ]  // 2~6개
    },
    "rivals": [  // 3~5개
      {"name": "BYD", "diff": "그 경쟁사와 비교해 무엇이 다른지·누가 어디서 앞서는지 (40~200자, 공정하게)"}
    ],
    "bull": [ {"point": "투자 포인트 한 줄 (10~80자)", "evidence": "근거: 공시 숫자·사실 (40~220자)"} ],   // 3~4개
    "bear": [ {"point": "걱정거리 한 줄 (10~80자)", "evidence": "근거 (40~220자)"} ],                     // 3~4개
    "watch": ["앞으로 확인할 것 (10~120자). 예: 분기마다 에너지 저장장치 설치량이 계속 느는지"],         // 2~4개
    "terms": ["glossary id"],   // 선택. jurini_app/assets/glossary.json에 있는 id만
    "sources": [ {"title": "Tesla 10-K (2025 회계연도)", "url": "https://www.sec.gov/..."} ]           // 4개 이상, 공시·IR 2개 이상
  }
}}
```

## 규칙
- 문장: 중학생도 이해하게, '~해요'체. 전문용어는 처음 나올 때 괄호로 풀기. 영어 약어 남발 금지.
- 밀도: 뻔한 말("혁신적인 기술", "강력한 브랜드") 금지. 대신 **구체적 사실·숫자·연도**. 숫자에는 기준(연도·분기·회계연도)을 붙인다.
- 사실 근거: 1순위 회사 공시(10-K, 10-Q, 20-F, 연차보고서, 주주서한), 회사 IR·투자자의 날 자료, 회사 공식 기술 블로그/발표. 2순위 정부·업계 기관 통계. 뉴스 기사는 사실 확인용 보조만(출처에 넣어도 되지만 공시·IR이 2개 이상 있어야 함). 위키·블로그·커뮤니티·AI 요약 금지.
- 확인 못 한 숫자는 쓰지 않는다. 회사 주장(목표)은 "회사는 ~라고 밝혔어요"처럼 회사 주장임을 드러낸다.
- 금지: 주가 숫자, 오늘 PER·시가총액 같은 매일 바뀌는 숫자, 목표가, 매수/매도/추천, "오를 것/내릴 것". (업종 평균 같은 일반 기준은 괜찮음)
- 경쟁 비교는 공정하게: 경쟁사가 앞서는 부분도 쓴다.
- 검사: `python check_deep.py deep_research/deep_N.json` 통과 필수.
